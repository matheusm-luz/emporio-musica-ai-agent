# CLAUDE.md — Empório da Música agent

Prototype customer-service agent for a fictional musical-instrument store (Artefact AI Engineer case).
Requirements live in `docs/SPEC.md` — read it before changing behaviour. Data findings in `docs/DATA_NOTES.md`.

## Non-negotiable rules

- **Sources of truth are only**: `data/*.csv`, `data/políticas_da_loja.pdf`, the challenge statement and
  the recruiter e-mail (summarised in `docs/SPEC.md`). Never invent store facts (partner stores, holidays,
  prices, names). If something is missing or contradictory, add an interpretation to SPEC.md and ask.
- **Never modify or rename anything in `data/`.** Loaders find files by glob.
- **KISS.** No new dependency, layer or abstraction without a SPEC requirement behind it.
- Business rules (prices, promotions, PIX, installments, availability, order privacy) are deterministic
  Python in `pricing.py` / `tools.py` — never delegated to the LLM.
- Example conversations in `examples/` are generated by `scripts/run_examples.py` — never hand-edited.

## Language

- Code, comments, docs, commit messages: **English**.
- Agent replies to customers: **Brazilian Portuguese** (or the customer's language). Tool outputs are PT-BR.

## Layout

- `src/emporio_agent/` — `config` (env) · `llm` (model factory) · `data` (CSV loading/cleaning) ·
  `pricing` (business rules) · `policies` (PDF → sections) · `tools` (LangChain tools) ·
  `tickets` (support tickets) · `prompts` (system prompt) · `graph` (LangGraph) · `cli` · `web`
- `tests/` — unit tests, no LLM calls. `evals/` — LLM behaviour suite. `examples/` — generated transcripts.

## Commands

```bash
uv sync                                   # install
uv run pytest                             # unit tests (fast, offline)
uv run ruff format . && uv run ruff check --fix .
docker compose up -d                      # Postgres for conversation history (optional)
uv run emporio-chat                       # CLI chat   (--session ID, --phone "(67) 9...")
uv run emporio-web                        # Gradio UI
uv run python evals/run_evals.py          # eval suite against LLM_MODEL
uv run python scripts/run_examples.py     # regenerate examples/
```

## Conventions

- Conventional Commits (`feat(tools): ...`), small commits per milestone, never force-push.
- Type hints everywhere; small pure functions; tests next to every business rule.
- Model is configured only via `LLM_MODEL="<provider>:<model>"` (`ollama:...` or `openai:...`).
